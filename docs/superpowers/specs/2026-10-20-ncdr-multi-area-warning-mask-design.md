# NCDR 多區告警遮罩設計

## 目標與已確認的資料

NCDR 強風 CAP `cwa-weather_strong-wind_202610201643001` 列出 55 個鄉鎮，沒有提供 polygon 或 circle；現有官方 area catalog 可逐一對上全部 55 個名稱。現行 collector 未讀取 `areaDesc`，改用全臺邊界集合的第一個 geometry，導致公開事件的 183 個 polygon 全在連江縣附近。App 又以其中最大 polygon 的 bounding box 中心作單一標點，造成誤導。

使用者確認遮罩應依 55 個鄉鎮上色，跨區警報改為點選上色區塊查看詳情，不保留單一標點。

## 資料流程

- Collector 從 CAP `info.area[]` 逐筆解析行政區，以官方 area catalog 的縣市加鄉鎮全名精確驗證；保留原始 CAP 與完整 catalog 在 Server 私有資料。若來源提供 polygon，維持來源 polygon 的優先權。
- 沒有來源 polygon 的多區 CAP，合併所有已對上的行政區邊界，使用僅供地圖展示的簡化幾何發布；公開事件附帶 `affected_area_ids`、`area_match_complete` 與未匹配名稱。不得以全臺集合的第一個 feature 當作多區警報範圍。
- 若只對上部分區域，告警文字仍發布，但 Web／Android 不繪製不完整的遮罩，並明示範圍未完整對應。官方目錄目前只有縣市與鄉鎮邊界；村里級 CAP 可保留其上層鄉鎮作為資料參考，但必須標為不完整且不可在地圖塗滿上層鄉鎮。連上層行政區都無法確認時，保留上一版有效資料並回報來源錯誤。
- 發布器既有的事件指紋與版本帳本會在幾何變更時遞增公開事件版本，使 Android 用新版取代先前錯誤範圍。
- 已簽章的公開 feed 仍依現有類別選取與事件版本機制發布。此批次不改完整 CAP 私有保存方式。

## 地圖與互動

- 既有「警報影響範圍」開關同時控制 CWA 縣市遮罩和已完整對應的 NCDR 多區遮罩，預設開啟。有效且尚未生效的告警依既有時間規則顯示，到期立即移除。
- NCDR 多區遮罩使用淡橘色、細邊線；點選任何上色區塊開啟同一筆告警，仍先處理原本的點標記命中。跨區 NCDR 事件不產生單一地圖標點。
- 從通知開啟跨區告警時，地圖顯示完整影響範圍與詳情。詳情標示「警報涵蓋行政區，非精確風害位置」，避免把整個鄉鎮說成每處都有強風。
- Web 和 Android 使用同一套 Flutter 地圖與詳情邏輯；更新後須分別驗證兩端取得新 feed、遮罩、開關及點選。

## 驗收

- 用 55 鄉鎮 CAP 範例驗證範圍涵蓋臺灣西部、東部與離島，未列入的鄉鎮不塗色；區域名稱不全時不畫錯誤遮罩。
- 驗證公開幾何的大小適合行動裝置，不再出現僅連江縣的 bbox；Web 與 Android 的地圖遮罩顯示、開關與點選一致。
- 保留目前工作樹其他修改；不提交、不部署。
