## 怎麼跑的

Samsung 接收端插 USB，由電腦用 adb 送 `cmd trials`（test_id、距離、備註、逾時、間隔、次數），等 CSV 多出對應列數；「環境」欄沒有 adb 參數，用 `uiautomator dump` 找到下拉選單再 `input tap` 選。Pixel 發送端不接電腦，換傳輸時在手機上按「發送端：開始提供／停止」。
