## 發布狀態

本報告記錄收集與品質檢查；簽章 bundle 只包含核實後的點位，以及供搜尋用的醫療名錄，不含原始明細或未核實點位幾何。Web 和 Android API 36 模擬器已用同一輪產物驗證下載與驗簽；Web 搜尋可找到已定位院所並跳至核實點位，也會把未定位院所標示為「尚未定位」。Android 離線冷啟動仍顯示底圖、圖層與告警。正式 Server 尚未部署、Android 實機尚未驗收；完成正式部署前，不可把此報告視為正式 App 已同步使用的即時數字。
